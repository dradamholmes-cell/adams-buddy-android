# Adam's Buddy for Android

This is an installable Android app for the private Buddy control center. Buddy, Game, Daily, and the site's own section links stay in an in-app WebView. Links to other sites open in the phone's browser. It provides native daily check-in notifications and one-tap launch from the phone's app list.

The daily reminder is generated by the phone at approximately 9 PM local time and opens Buddy when tapped. It does not yet deliver live PC events. The private Buddy Site needs a separately paired, authenticated notification channel for that. WebView has its own cookie store; private Site sign-in on a phone must be tested. Some identity providers reject embedded sign-in.

The app contains no API keys or PC bridge secret. The source can be built with Android Gradle Plugin 8.13, Gradle 8.13, and JDK 17. `:app:assembleDebug` creates a test APK.

To install a test APK, download the build artifact, unzip it, open the APK on your Android phone, and allow installation from your file manager if Android asks. Open Buddy and try the private sign-in. Use the top right menu for **Turn on daily reminder** and **Test notification**. This test APK uses temporary debug signing; an older test version may need to be uninstalled before installing this one.
