# Adam's Buddy for Android

This is an installable Android entry app for the private Buddy control center. It opens Buddy in a Custom Tab so the phone's browser can use the existing sign-in session. It provides native daily check-in notifications and one-tap launch from the phone's app list.

The daily reminder is generated by the phone at approximately 9 PM local time and opens Buddy when tapped. It does not yet deliver live PC events. The private Buddy Site needs a separately paired, authenticated notification channel for that.

The app contains no API keys or PC bridge secret. The source can be built with Android Gradle Plugin 8.13, Gradle 8.13, and JDK 17. `:app:assembleDebug` creates a test APK.

To install a test APK, download the build artifact, unzip it, open the APK on your Android phone, and allow installation from your file manager if Android asks. Open Buddy and sign in through the phone's browser if needed. After closing the Buddy tab, use **Turn on daily reminder** and **Test notification** on the native app screen.
