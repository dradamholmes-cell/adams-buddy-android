# Adam's Buddy for Android

This is an installable Android app for the private Buddy control center. Buddy, Game, Daily, and HTTPS links stay in an in-app WebView so the private sign-in redirect chain uses one cookie store. It provides native daily check-in notifications and one-tap launch from the phone's app list.

The native Watch screen is designed for the user's AM06C screenshots and companion app data. It sends a generic phone test notification for the existing watch companion app to mirror, opens Buddy's Android notification settings, and exports 512×512 Buddy or arcade-themed PNG backgrounds for the companion app's Watch Face Gallery → Custom tab. It also opens the installed `com.sma.smartv3.pro` watch app. It does not pair to or write to the watch over Bluetooth. The watch appearance and notification delivery require a phone test.

**More** has Buddy Blaster, a tiny original first-person arcade game rendered at about 15 frames per second, and Buddy TV, which plays a video the user selects locally with Android's document picker. Arcade score is not money. Neither feature streams video to the watch or uploads selected videos.

The daily reminder is generated by the phone at approximately 9 PM local time and opens Buddy when tapped. It does not yet deliver live PC events. The private Buddy Site needs a separately paired, authenticated notification channel for that. WebView has its own cookie store; private Site sign-in on a phone must be tested. Some identity providers reject embedded sign-in.

The app contains no API keys or PC bridge secret. The source can be built with Android Gradle Plugin 8.13, Gradle 8.13, and JDK 17. `:app:assembleDebug` creates a test APK.

To install a test APK, download the build artifact, unzip it, open the APK on your Android phone, and allow installation from your file manager if Android asks. Open Buddy and try the private sign-in. Use **Watch** for the test alert and custom face, or **More** for the daily reminder. Versions before 0.6 used temporary debug signing and must be uninstalled once. Version 0.6 and later use the persistent signing key held outside this public repository and in repository Actions secrets, so subsequent versions can update it in place.
