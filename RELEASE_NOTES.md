Adam's Buddy Android watch and update test

Install the APK on an Android phone, then tap the Buddy icon. Buddy and the HTTPS sign-in redirect chain stay inside the app. The updated header has Talk, Game, Daily, Watch, and More. Watch can send a phone alert that your existing watch app may mirror, and save a Buddy PNG for Watch Face Gallery → Custom. Use More for the optional 9 PM daily check-in notification.

This is a test APK. Private sign-in and watch mirroring need phone tests. Some sign-in providers refuse embedded login. The watch face is an image, not a live clock or video stream. The app does not yet send live PC or task alerts, and it needs the internet for Buddy content. Uninstall the previous test app once; this and future builds use one persistent signing key. No API keys or PC bridge credentials are packaged in the app.
